# Эксплуатация

## Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---|---|
| `TELEGRAM_TOKEN` | да | токен от [@BotFather](https://t.me/BotFather) |
| `STEAM_API_KEY` | желательно | ключ Steam Web API, [получить](https://steamcommunity.com/dev/apikey). Без него источником матчей становится OpenDota |
| `OPENDOTA_API_KEY` | нет | снимает лимит 60 запросов в минуту |
| `DOTA_MANUAL_SALTS` | нет | ключи реплеев вручную, формат `матч:кластер:ключ` через запятую |
| `DB_PATH` | нет | путь к базе, по умолчанию `bot.db` рядом с бинарником |

Админ в конфиге **не задаётся**: им становится первый зарегистрировавшийся, пока
в базе нет ни одного админа. Поэтому первым `/start` должен сделать владелец
бота. Дальше админы назначаются через `/users`.

## Сборка и запуск

```bash
go build -o n-dota-stats ./cmd/n-dota-stats
./n-dota-stats
```

Зависимостей за пределами Go-модулей нет: SQLite — чистый Go (`modernc.org/sqlite`),
телеграм и HTTP — стандартная библиотека.

## systemd

```ini
[Unit]
Description=n-dota-stats
After=network-online.target

[Service]
WorkingDirectory=/opt/n-dota-stats
Environment=TELEGRAM_TOKEN=...
Environment=STEAM_API_KEY=...
Environment=DB_PATH=/var/lib/n-dota-stats/bot.db
ExecStart=/opt/n-dota-stats/n-dota-stats
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

## Что происходит в фоне

| Задача | Интервал |
|---|---|
| опрос истории матчей пользователей | 15 минут, после трёх часов затишья — час |
| разбор очереди метаданных | вместе с опросом, по три матча за проход |
| обновление снимка перцентилей | дважды в сутки, около 126 запросов за проход |

Матч скачивается один раз на всех пользователей: заявка ставится атомарным
переходом состояния `none → queued`, повторные вызовы возвращают «уже занято».

## Лимиты и деградация

- **Game Coordinator**: свой суточный бюджет в 80 заявок при лимите Valve около
  ста. Исчерпан — матчи ждут следующих суток, сводка по итоговой таблице уже
  отправлена.
- **OpenDota**: троттлинг в одну заявку в секунду. Сервис недоступен — работает
  предыдущий снимок перцентилей.
- **Steam Web API**: если ключ не задан, источником матчей становится OpenDota.

Отказ любого источника не роняет бота: он опускается на тот уровень данных,
который доступен, и помечает это в сводке.

## Резервная копия

Всё состояние — один файл SQLite. Достаточно копировать `bot.db` (вместе с
`-wal` и `-shm`, если бот запущен, либо после остановки).


## Запуск без systemd

Если ставить службу не хочется, бот можно отвязать от терминала вручную:

```bash
cd /путь/n-dota-stats
set -a && . ./.env && set +a
setsid nohup ./n-dota-stats --db bot.db >> bot.log 2>&1 < /dev/null &
```

`setsid` заводит процессу собственную сессию, `nohup` снимает реакцию на
обрыв терминала, перенаправления отвязывают его от консоли. После этого бот
переживает закрытие оболочки, из которой был запущен: когда та завершится, он
перейдёт к init.

Проверить, что отвязался:

```bash
ps -o pid=,ppid=,sid=,tty= -p $(pgrep -x n-dota-stats)
```

Третье число должно совпадать с первым — это значит, что процесс сам себе
сессия, — а вместо терминала стоять вопросительный знак.

Дальше:

```bash
tail -f bot.log        # смотреть, что происходит
pkill -x n-dota-stats  # остановить
```

Чего этот способ не даёт: бот не поднимется сам после перезагрузки машины и
после падения. Для этого нужен systemd — юнит выше.
